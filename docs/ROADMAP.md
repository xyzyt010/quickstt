# Roadmap

## Near Term

- stabilize Windows release quality
- clean and slim packaged output size
- improve release automation
- harden update and packaging flows
- improve cloud provider UX and diagnostics

## Platform Expansion

### macOS

First non-Windows target:
- native app packaging
- device permissions and microphone handling
- text injection and accessibility flows
- packaged local STT runtimes

### Linux

After macOS:
- AppImage / distro packaging strategy
- microphone and desktop environment integration
- Wayland and X11 input constraints
- GPU runtime compatibility planning

## Runtime Expansion

- broader Whisper-family support
- cleaner GPU backend packaging
- better model/runtime lifecycle management
- improved update delta strategy

## Community Help Wanted

- macOS engineers
- Linux desktop packagers
- STT and inference specialists
- networking and release engineering contributors
- documentation and testing contributors
